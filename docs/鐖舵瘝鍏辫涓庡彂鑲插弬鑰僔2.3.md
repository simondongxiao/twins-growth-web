# V2.3：父母共记、主体归属、发育参考

## 日常入口

仍然只写一段话。第一次点爸爸或妈妈，以后记住。可以在任何孩子页写两人，文字中的明确主体优先于页面；没有名字才以当前页作为默认。比较页不写对象时保存为待核对，而非默认两个人都会。

归档预览默认折叠，含不确定对象时展开；可在保存前或历史中点选归属。原话整段、拆分片段、报告时间、发生时间与推断依据均保留。缺少发生日期时不造日期；“上周”保留自然周区间；同段明确更换日期时分别解析。

这是本地规则解析，不是接通了大模型。常见并列句和别名可处理；复杂反讽、省略、多层转述不保证正确，不确定时留待核对。父母仍可导出同一份事实给GPT/Gemini复盘。外部AI无权自动改写原始证据。

## 存储兼容

底账schema_version继续为2。source_report保存原段，observation.attribution引用source_id与UTF-16片段边界，修正时生成替代片段与撤回事件。profile/milestone_check保存家长核对，不混进生日配置。旧版本记录和阿姨署名不改写。

一段的原段与所有片段在电脑、本机模式按批次保存。云端仍通过现有同步重试机制上传事件，短暂断网可能让另一设备只看到部分已上传片段；以完整上传确认和后续重试结果为准，不承诺分布式事务。父亲归档会生成原始口述与拆分索引.md、发育参考与观察对照.md及原有档案。

## 界面位置

顶部：大宝 / 小宝 / 大宝小宝比较。
底部：记一笔 / 历史 / 发育参考 / 同步。

记录卡片只显示折叠的“相关发育参考（未自动判定）”。参考页分别呈现18、24、30个月的精选观察点；同胞比较保持各自状态，不计算能力差值。

## 发育参考的边界

CDC节点是至少75%儿童到该年龄可见的表现，不是平均首次出现时间或高能力常模。因此不能由“提前做到了”计算领先月数，不能由缺少日志推断迟缓。页面只用：已观察到（家长核对）、待补观察、家长报告尚未出现、到节点请重新核对、建议咨询儿保。

关键词关联即使命中了“说话/踢球”，也不自动打勾；可能是不会、模仿、尝试或提到了另一人。家长核对可关联已有原话，也可以保留不确定。此功能不要求每次、每天使用。

“两个词”不是“两个汉字”。“打开”是一个词，固定“大家好”也不能仅按字数当作灵活组合；要记录实际场景。认数字、动物种类和连续拍球没有在本清单设立年龄门槛。

出现能力倒退、明确没有出现参考节点能力或持续担忧时，应联系儿保/儿科，不能等24个月再判断。网页不是临床筛查，更不是智商测试。出生孕周未确认，不计算矫正月龄；这些公开观察点不替代上海当地儿保实际安排。
