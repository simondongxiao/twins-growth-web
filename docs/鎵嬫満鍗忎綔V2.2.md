# 手机记录、家人历史与一键归档

## 日常录入

打开固定网页地址，选择大宝或小宝，写一句观察，点保存。记录者在各自设备点一次。可以用系统键盘语音转文字；本程序不请求麦克风或照片权限。

没有日期时保留未知；“昨天”按保存时的报告日和家庭时区解析；“上周”保留自然周区间。出生日期来自私有家庭资料，公开代码不内置。

抽屉中的日期、场景、提示、分类均可不填。不强制每日记录，不把认数字、语言和运动做成打分任务。

## 三种存储事实必须分开

1. **本机已存**：浏览器已保存原话。没有证据说明另一台设备已经收到。清理缓存、无痕会话结束、浏览器回收存储可能导致本机数据丢失；不要把本机缓存当长期唯一备份。
2. **已上传家庭云端**：写入后读回相同ID和内容，才能标记。妈妈可离线补记到已打开的页面；保存、联网恢复、前台刷新会尝试重传。页面关闭或手机系统挂起时不承诺继续上传；以“已上传”回执为准。网络恢复不代表已确认上传。
3. **电脑归档已确认**：本地程序已写JSON和Markdown，并产生包含本批事件ID的回执。回传云端成功后，妈妈也会看到。它不是爸爸阅读或批准了内容，也不证明孩子掌握了能力。

可选第四状态 **GitHub私有备份已确认**，仅在GitHub返回非强制提交成功后出现；失败时仍保留电脑归档成功，不混淆两者。

## 妈妈的操作

“记一笔”→保存。首次在自己的私人设备登录家庭账号，可自愿勾选保持登录；共用设备不要勾选。登录凭据不是GPT/Gemini账号。

“历史”可切换全部、我记录的、妈妈记录、待归档、已归档。撤回后保留原话及撤回事件，不真正删除审计历史。已撤回不等于公开或云端永久删除。

记录者名称是家庭内的显示标签，不是访问控制；访问权限取决于Supabase账号与家庭成员表，不取决于点击“爸爸/妈妈”。

## 爸爸的操作

启动电脑的 `start_local.bat`，打开该本地网页，底部“同步”→“一键更新并保存到电脑”。程序顺序：

- 登录已配置的家庭云，拉取原始事件；按不可变ID合并。相同ID不同内容停止，不选更新的日期覆盖另一份。
- 更新电脑JSON和Markdown；保存归档回执。重复点击不重复增加同一观察。
- 勾选且已配置私有GitHub备份时，另外提交白名单快照。
- 把归档回执回传家庭云。回执上传失败时标注待重试，妈妈的状态不假装变化。

爸爸在手机上的同一个公开网页只能刷新家庭云记录；**它不能直接写D盘**。必须在电脑运行本地程序，或使用本包CLI。电脑关机时妈妈仍可上传到已经配置好的云端；电脑下次运行后归档。

`one_click_sync.bat`只运行一次。旧 `start_sync.bat` 可以持续同步事实到电脑，但本版“归档回执”由一键归档命令产生；没有回执不意味着记录一定没写过电脑，只代表当前未获得这一确认。

## 未部署云端时的替代流程

妈妈“同步”→展开文件交接→“发给爸爸 / 导出交接包”。手机支持系统文件分享时调起分享；否则下载JSON，再通过现有通信工具发送。

爸爸“导入家人记录”→按ID合并。之后点一键保存。无共同云端时不能远程把回执推回妈妈手机；需要爸爸再导出一份合并后的JSON给妈妈导入。

这个替代流程不需要新服务账号，但不是全自动同步。

## GitHub为什么不直接当手机数据库

GitHub Pages提供静态网站托管，普通网页不会自动获得写仓库或访问电脑磁盘的权限。公开的前端文件不是存放儿童事实或长期写入令牌的地方。

本版采用：公开程序仓库 + 私有家庭云数据库 + 可选独立私有备份仓库。前端只使用允许公开的Supabase连接信息，写入由登录及行级权限控制；不能把service_role、secret key或GitHub token嵌入HTML。

### 私有GitHub备份如何启用

在用户自己的GitHub账号中创建独立的**私有、带README、不开启Pages**的数据仓库；不要使用公开网页的代码仓库。安装gh并在本机登录。运行 `configure_github_backup.bat`，输入 `OWNER/REPO`；程序核实私有性和Pages状态。

回到本地网页后，勾选“同时备份到独立私有GitHub仓库”，再点一键更新。上传仅包含验证过的growth.json与程序重新生成的Markdown。**不遍历整个private目录**，不会上传cloud.local.json、登录密码、系统文件、HTML预览、照片或其他项目。

每次备份生成 `archives/<时间-随机后缀>/` 和 `latest.json`。创建Git提交并以force=false推进分支；并发导致冲突则停止，不强推。仓库不是私有、已开启Pages、未配置、登录失败或权限不足时，拒绝备份并保留本地数据。

配置保存和勾选是用户对该次数据上传的操作；本包不自动创建远端仓库或后台计划任务。

## 更新安全与边界

已有私有事件和配置保留，旧源码先备份。程序生成的Markdown会被重新生成，不应手改它来补原始事实；请在网页追加说明。

本系统没有接入GPT/Gemini API；“复制复盘材料”之后，由用户交给模型。保存原话不会自动触发训练计划加码。
