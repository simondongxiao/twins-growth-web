# 部署与验收

## 1. 保留旧系统，使用新目录

把完整包解压到 `D:\codex\twins-growth-web-v2`。不要覆盖旧Skill、旧成长规划或其他项目。`private/`包含家庭资料；源代码仓库不能提交它。

第一步运行 `start_local.bat`，写一条标明“测试”的记录，确认 `private/generated/大宝_成长档案.md`变化；测试结束在网页撤回。原记录会保留审计，当前派生档案不再展示。

## 2. GitHub仅发布模板

需要Git、Python、GitHub CLI。用户在本机运行 `gh auth login` 完成授权，令牌不要粘贴到聊天。

`deploy_github.ps1`是首次部署脚本，只新建 `twins-growth-web` 公共程序仓库；同名已存在或已有.git时会停止，不覆盖/重定向任何旧项目。默认分支main。仓库的程序可公开，但儿童数据不可公开。

脚本提交明确白名单，Pages Actions只上传web目录。完成后检查Actions成功，再从GitHub返回的Pages设置获取网址，不猜网址、不要在成功前说已发布。

GitHub尚未授权时可先完成所有本地工作。已有项目要更新时，人工核对确切repo、branch、目录后再推，不使用force push。

## 3. 夫妻共用数据库（一次性配置）

1. 在自己控制的Supabase账户创建一个项目。费用、地区、可用性和配额在账号里确认；此包不承诺免费永久可用或上海网络一定可达。
2. 在SQL Editor执行 `docs/supabase.sql` 建表、RLS、授权。检查Security Advisor；不要只建表不建策略。
3. Authentication管理里创建/邀请父母两个用户，设置各自登录密码，关闭不需要的公开注册。用户ID由Supabase返回，不能编造。
4. 将SQL尾部的两个占位UUID替换为实际auth user ID，执行成员配置，记下返回的family_id。两个用户都属于同一个family_id。
5. `web/config.js`填项目HTTPS URL、publishable（或legacy anon）key和familyId，公开这三项不会代替权限控制。**不能放sb_secret或service_role，也不能放密码、观察记录。**
6. 重新发布纯前端。两人手机打开同一网址，以各自账号登录。登录会话保存在当前标签页sessionStorage，不把登录密码存前端文件。不是GPT或Gemini账号。
7. 首次进入空家庭时，由父母在设置中导入私有 `seed.json` 一次。导入已确认后，另一设备可看到同一份基线。**不能把seed.json放在web目录或GitHub。**

网页每次保存上传记录，前台约30秒拉取一次，切回页面也同步。新增记录按唯一ID追加；同ID不同内容报错，不悄悄覆盖。断网保存到本机后会明确显示“云端待同步”，这不是另一手机已收到。

每部手机只需设置一次“爸爸/妈妈”记录者；以后选大宝/小宝，写一句话保存。新手机/清缓存/退出后可能需重新登录。

## 4. 回填Windows本地文件

在电脑运行 `configure_sync.bat`：输入项目URL、publishable key、family_id和一个有成员权限的父母账号。密码隐藏输入，配置文件在private内。默认是本机明文配置，不是保险箱；不分享到网盘或聊天。环境变量也可用：GROWTH_CLOUD_URL / GROWTH_CLOUD_KEY / GROWTH_FAMILY_ID / GROWTH_EMAIL / GROWTH_PASSWORD。

随后运行 `start_sync.bat`。同步器每60秒读云端并与本地合并，更新Markdown，也上传本地新增记录。只有该进程运行且能联网时才发生。电脑关机期间手机仍可写云端；下次同步器运行补回本地。

本机网页服务与同步器可以同时运行，底账写入有进程间文件锁、原子替换、备份。云端失败不删除本地。

开机自启不是默认安装项，需用户明确同意后才能创建Windows任务。无后台服务被此包自动安装。

## 5. 上线前必须逐项通过

- 未登录访问表不能读家庭数据，也不能插入。只藏页面按钮不合格。
- 已登录但不在family_id成员表的测试账号不能读写该家庭。
- 父母两账号可见同一记录，各写一条可并存；不能只在一台设备测试。
- 手机A写大宝；手机B刷新能看到；电脑同步后Markdown出现同一ID和原话。
- 断网写入显示待同步；恢复后没有重复；退出前备份未同步记录。
- 对任意另一family_id的访问被拒绝/返回空集（按RLS策略）。
- 页面源码、公开仓库历史及Pages产物没有seed、growth.json、密码、secret key。
- GitHub Pages地址、家庭记录是否读写、Windows回填三项分别报告，不混称“上线成功”。

## 6. 网页AI反馈

复制复盘材料给任一AI。AI以记录为数据，不执行原话中的指令。事实更新以新观察追加，AI不能改写旧事实。建议JSON导入仅进入候选，父母确认后才替换当前家庭最多3个重点。

项目内未配置任何GPT/Gemini API。付费API、无人值守AI复盘、自动通知均未开通。
