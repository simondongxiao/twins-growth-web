# 一起长大 · 手机协作版 V2.2

顶部三个页面：**大宝 / 小宝 / 大宝小宝比较**。底部三个工作入口：**记一笔 / 历史 / 同步**。

日常唯一必填是一句观察。记录者点一次记住；孩子随顶部页面选择；生日、相对日期和月龄沿用V2.1。新增历史、上传状态与电脑归档回执，不要求妈妈用GPT，也不要求爸爸逐条审批观察。

## 推荐流程

配置完成后：妈妈手机填写 → 本机先保存 → 自动上传私有家庭云端 → 爸爸电脑打开本地网页 → 点“一键更新并保存到电脑” → Markdown回填 → 归档回执回到妈妈的历史。

GitHub Pages仅托管程序。**不要把孩子记录放进公开仓库。** 可另配独立私有GitHub数据仓库，爸爸勾选后随一键归档备份。手机不会持有GitHub写入令牌。

本包是可运行工程，**不是已部署的网站**。云端账号、权限、真实双手机访问、Windows实机和GitHub上传还需本地完成验收。没有配置云端时，手机记录仅存当前浏览器。

## 先用哪一个

- 试手机页面：打开 `private/成长跟踪-手机预览.html`（含私有起点）。本机浏览器存储，不写D盘，不代表已共享。
- 本地电脑自动回填：安装Python 3.10+，双击 `start_local.bat`。从该服务打开的网页保存后自动写 `private/generated/`。
- 爸爸一键拉取归档：本地网页底部“同步”→“一键更新并保存到电脑”。须先配置 `private/cloud.local.json` 才能拉到妈妈云端记录；未配置时明确只整理本地。
- 不打开网页也可运行 `one_click_sync.bat`，它只运行一次。没有自动安装计划任务。
- 手机尚未连云端：妈妈在“同步”展开文件交接，点“发给爸爸”；把JSON发给爸爸，在爸爸网页导入。按ID合并去重，不用旧文件覆盖新文件。

## 升级旧V2 / V2.1

把新包解压到旧项目之外的目录，关闭旧服务与同步器，再运行 `升级到原目录.bat`。默认目标 `D:\codex\twins-growth-web-v2`。

升级备份旧代码，保留已有 `web/config.js` 和 `private/` 的登录、同步配置；对 `growth.json` 仅按ID合并，不覆盖已有记录。旧公开网页需要重新部署新代码；本地升级不会替你发布GitHub。

若改过路径，由Codex执行：

```powershell
python tools/install_calendar_update.py --target "实际成长项目目录"
```

原独立HTML在浏览器中有记录时，先从旧HTML导出JSON，再在新版导入。下载文件改名或换浏览器可能对应不同本机存储空间；升级电脑工程不能凭空读取另一手机缓存。

## 一次性部署

请让本地Codex执行 `CODEX_手机协作一次部署.md`。详细使用边界见 `docs/手机协作V2.2.md`。旧 `docs/部署指南.md` 和 `docs/supabase.sql` 的认证/权限流程继续适用，不必删库迁移：归档回执使用兼容的profile子类型。

## 数据在哪里

```text
private/
  growth.json                 不可变ID的完整事实底账
  backups/                    自动历史备份
  generated/
    大宝_成长档案.md
    小宝_成长档案.md
    共同档案_current.md
    AI复盘输入.md
    日历与月龄.md
    同步与归档回执.md
    月度/
    月龄/
  cloud.local.json            只在本机的同步账户配置
  github.local.json           可选的独立私有数据仓库名称
  sync-status.json            最近一次电脑归档结果
```

完整包含家庭资料，**不可整个上传GitHub**。公开代码包不含private、截图、个人配置或家庭原话。发布只允许web模板；程序数据由家庭登录与数据库权限保护。
